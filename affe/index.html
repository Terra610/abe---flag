What AFFE Does

AFFE is the funding normalization and appropriation fidelity layer of A.B.E.

It helps turn messy funding documents into structured artifacts, then evaluates whether funding, appropriation purpose, scope conditions, and deployment remain aligned.

Plain language: Did the funding stay connected to the purpose it was allocated for?

Two Jobs, One Module

Job 1
Normalize Funding Documents

AFFE can support CSV, spreadsheet, PDF, text, or structured funding inputs and convert them into analysis-ready artifacts.

Job 2
Measure Fidelity + Stability

AFFE reads RT, CII, Integration, and CFF outputs to evaluate funding fidelity and post-deployment stability.

Run AFFE Stability / Fidelity Check

Use this when upstream outputs already exist from the full pipeline. For most users, the easiest path is still System → Run Full Pipeline.
