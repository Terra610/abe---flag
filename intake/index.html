How this works

  1. Your file or text is processed only on this device.
  2. Run Full Pipeline runs the fixed engine chain and builds an audit report.
  3. Read the plain-language summary, or open the JSON tab for the full artifact.
  4. Download Artifact saves the report (includes SHA-256 hash when available).
  5. Clear wipes local case data so you can start a different case — like clearing a calculator.

Advanced modules (CIRI, CFF, doctrine, etc.) stay available from Home → Advanced Engine. This page is the simple path for one case.
