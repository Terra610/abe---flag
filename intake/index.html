What happens next?

  1. Intake builds a local artifact and stores it in your browser.
  2. Go to System Dashboard and run the full pipeline (order is fixed and never changed).
  3. Or open individual modules (CDA, CIRI, CFF, etc.) — they can pick up the intake artifact automatically.

Pipeline order is protected: INTAKE → CAE → CDA → CDI → CIRI → CIBS → CII → INTEGRATION → MACRO → RT → CFF → CCRI → AFFE.
