# 🦋 The American Butterfly Effect (A.B.E.)

**A deterministic constitutional capital discovery, recovery, and deployment framework**  
_Local-only · auditable · no backend · no login · no black box_

---

## 🌍 Overview

The American Butterfly Effect (A.B.E.) is a modular deterministic framework that identifies constrained capital flow inside complex systems, quantifies recoverable value, models deployment pathways, and verifies post-deployment stability.

A.B.E. transforms structured inputs into measurable outputs:

```text
system friction
→ measurable signal
→ recoverable capital
→ structured allocation
→ deployment
→ economic activation
→ stability verification
```

The framework runs locally in the browser and does not require:
- a server
- user accounts
- API keys
- centralized infrastructure
- backend databases
- cloud execution

Everything remains transparent, inspectable, and auditable.

---

## 🎯 What A.B.E. Is For

A.B.E. is designed to help users, organizations, agencies, researchers, investors, and communities understand where value is being constrained and how much economic capacity can be recovered through better alignment, allocation, and deployment.

The framework focuses on measurable structure rather than ideology.

A.B.E. answers practical questions such as:

- Where is capital flow being restricted?
- How large is the recoverable value pool?
- Which sectors produce the strongest activation effect?
- How should recovered value be allocated?
- Does deployment improve measurable stability?
- Can the entire process be verified and audited?

Rather than relying on assumptions or opaque models, A.B.E. converts structured signals into deterministic outputs.

# 📐 Core Formula Chain

## CDI — Shouse Divergence Curve

```text
S_r = (w1 · s1) + (w2 · s2) + (w3 · s3) + (w4 · s4) + (w5 · s5)

CDI = 1 - e^(-S_r / R)
```

CDI converts structured divergence signals into a normalized index.

---

## CIRI — Recovery / ROI Function

```text
R_T =
(C_a · C̄)
+ F_e
+ (C_a · D_j · J)
+ (P_e · Ē)
+ (H_r · M̄ · t̄_a)
+ (C_a · P_e · w̄ · t̄_a)
+ (L_e · P̄ · λ)
- T_c

CIRI = 1 - e^(-R_T / K)

ROI_case = R_T / C_a
```

CIRI converts measured divergence into recoverable capital and return-on-alignment estimates.

---

## CIBS — Shouse Baseline Allocation Function

```text
B_i = R_T · p_i

Σ B_i = R_T

B_i,q = B_i · f_q
```

CIBS distributes recovery capital into structured allocation pathways.

---

## CII — Shouse Alignment Propagation Model

```text
CII = Σ ((B_p / R_T) · η_p · w_p)
```

CII measures propagation effectiveness after allocation.

---

## RT — Rebuild Together Deployment Function

```text
D_i = B_i · a_i

A_i = D_i · m_i · η_i

A_total = Σ A_i

RTI = Σ ((D_i / D_total) · η_i · w_i)
```

RT models deployment, activation, and execution readiness.

---

## AFFE — Stability Function

```text
S = (RTI · η) + (A_total / R_T)

AFFE = 1 - e^(-S / K)
```

AFFE measures post-deployment stability after activation.
