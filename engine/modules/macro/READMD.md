# Macro — Macro Cascade Module

**Purpose**:  
Shows the national and global "butterfly effect" of constitutional realignment. Calculates compounded savings, job creation, GDP uplift, and downstream impacts from local corrections.

**Part of Firing Order**:  
... → affe → ciri → cibs → cii → **macro**

**Core Responsibilities**:
- Takes divergence scores and CIRI ROI outputs
- Applies 1.8× multiplier for constitutional capital
- Projects 5-year national/global ripple effects
- Visualizes how fixing one area (e.g. traffic stops, subsidies, evictions) cascades into broader prosperity

**Inputs**:
- `derived.divergence`
- `derived.ciri`

**Outputs**:
- `derived.macro` — { base_divergence, sigma_divergence, constitutional_capital, national_impact, ... }

**Key Features**:
- Uses original ABE formulas (protected)
- Supports 0-1 + 2σ–4σ divergence layers
- Fully client-side and auditable with SHA-256 receipt

This module is part of the open, non-commercial ABE framework. It exists to make constitutional realignment measurable and actionable. No monetization, no commercial wrapping allowed.
