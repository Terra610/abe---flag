# CIBS — Community Budget & Integrity System

**Purpose**:  
Takes constitutional capital unlocked by CIRI and intelligently allocates it into community priorities (housing, public safety realignment, youth centers, job training, agriculture soil health, legal access). Turns recovered funds from unconstitutional practices into tangible public benefit.

**Part of Firing Order**:  
... → affe → ciri → **cibs** → cii → macro

**Core Responsibilities**:
- Receives CIRI ROI outputs
- Allocates funds using transparent percentages (40% housing, 25% public safety transition, etc.)
- Ensures no new taxes — money comes only from ending misuse
- Produces auditable allocation with SHA-256 receipt

**Inputs**:
- `derived.ciri` (constitutional capital unlocked)
- `derived.divergence` (for sigma scoring)

**Outputs**:
- `derived.cibs` — detailed allocation breakdown

**Key Features**:
- Fully deterministic and local-only
- Supports original ABE 0-1 + 2σ–4σ divergence layers
- Transparency-first: every dollar is traceable
