# CAE — Constitutional Authority Evaluator

**Purpose**: Evaluates whether government actions, regulations, or enforcement stay within constitutional authority bounds (ultra vires detection).

**Firing Order Position**: After system, before divergence.

**Key Features**:
- Authority scoring (0-1 + sigma layer)
- Ultra vires detection
- Feeds directly into divergence analysis
