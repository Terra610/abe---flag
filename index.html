American Butterfly Effect

A.B.E. is a constitutional integrity, recovery, and deployment framework that helps users measure divergence, quantify recoverable value, model deployment pathways, and verify funding fidelity and stability.

Start Here Upload / Intake Run Full Pipeline Build Audit Receipt

Plain-Language Overview

A.B.E. is built so a user can upload once, run the engine, and receive a readable result plus an audit-ready JSON artifact.

The user does not need to understand every module first. The advanced modules remain available for people who want to inspect the math, law maps, funding logic, deployment model, and audit chain.

The goal is simple: identify what drifted, calculate what it cost, model what can be recovered, show where recovery can go, and verify whether deployment remains stable.

Privacy Model

A.B.E. is local-first. It does not require a backend, login, account, API key, database, or cloud processing layer.

Users control their own inputs, outputs, JSON artifacts, and audit receipts.
