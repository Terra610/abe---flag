Doctrine Execution Order

CCRI is not a front-end scoring toy. It is a downstream constitutional capital module. The order assumed here is:
  • CAE: constitutional alignment / clause integrity
  • CDA or CDI: definition integrity / divergence
  • CFF: funding alignment
  • Jurisdiction validity gate
  • CCRI: constitutional capital suppression and recovery
  • CIRI: injury / risk / recovery integration
