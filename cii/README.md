# CII — Constitutional Integration Interface

## Function

CII integrates outputs from all upstream modules into a unified, deterministic result.

It consolidates divergence, funding alignment, financial exposure, recovery, and system behavior into a single structured output.

---

## Input

- CDA (divergence classification)
- CFF (funding alignment)
- AFFE (financial exposure)
- CIRI (impact and recovery)
- CIBS (system behavior and feedback)

---

## Output

- Unified system result
- Total divergence profile
- Total financial exposure
- Total recovery potential
- System behavior summary
- Structured output artifact

---

## Integration Logic

CII performs:

- Consolidation of all module outputs
- Alignment of divergence conditions across domains
- Aggregation of financial and recovery metrics
- Structuring outputs for downstream use

No input is altered.  
All inputs are preserved and combined.

---

## Deterministic Rule

All module outputs are integrated.

No module operates independently at this stage.

The final output reflects the total system condition.

---

## System Position

Upstream:  
- CDA  
- CFF  
- AFFE  
- CIRI  
- CIBS  

Downstream:  
- Integration layer (UI / user output)  
- Macro (aggregate scaling and modeling)

---

## System Role

CII acts as the convergence point of the A.B.E. system.

It produces a complete and traceable representation of divergence, cost, and recovery.

---

## Output Dependency

- Integration layer presents CII output to the user
- Macro uses CII output for large-scale modeling and projections

---

## Core Principle

All system outputs are connected.

CII ensures that divergence, cost, and recovery are represented as a single, unified condition.

---

## Result

CII produces a deterministic, structured output of the full A.B.E. calculation.

This output defines the total system state for the evaluated inputs.
