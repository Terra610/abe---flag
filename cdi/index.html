CDI — Constitutional Divergence Index

Core pioneer divergence module. CDI computes the weighted structural divergence signal S_r and transforms it into a bounded divergence score using the Shouse Divergence Curve.

Canonical Formula Stack

CDI executes the original pioneer divergence formulas:
  • S_r = w1·s1 + w2·s2 + w3·s3 + w4·s4 + w5·s5
  • CDI = 1 - e^(-S_r / R)
Where: s1 = stops per 1,000 residents, s2 = charge mix ratio, s3 = average time-to-counsel, s4 = dismissal rate, s5 = pretext ratio.
