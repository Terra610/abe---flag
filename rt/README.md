# RT — Rebuild Together Engine

## Purpose
Transforms allocation outputs into structured capital deployment and measurable economic activation.

## Function
Converts CIBS-derived allocations into sector-level distribution and community-level execution pathways.

## Inputs
- CIBS allocation outputs
- CII propagation scores
- MACRO projections

## Outputs
- deployment allocations
- sector distribution plans
- economic activation signals
- community execution mapping

## Role in Pipeline
Bridges allocation (CIBS) and real-world execution prior to AFFE feedback.

## Deterministic Behavior
RT operates on fixed allocation and propagation inputs. Identical inputs produce identical deployment structures.

## Economic Relevance
Represents the transition from theoretical capital recovery to applied economic activity, enabling scalable growth without external capital injection.

## Notes
RT does not introduce new capital. It activates existing recoverable value through structured deployment.
