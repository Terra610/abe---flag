CIRI — Constitutional Integrity Risk Index

Core pioneer module. CIRI computes the total constitutional risk and recovery term R_T, then normalizes it into a bounded constitutional risk index and case ROI.

Canonical Formula Stack

CIRI executes the original pioneer formulas in this order:
  • R_T = (C_a·C̄) + F_e + (C_a·D_j·J) + (P_e·Ē) + (H_r·M̄·t̄_a) + (C_a·P_e·w̄·t̄_a) + (L_e·P̄·λ) - T_c
  • CIRI = 1 - e^(-R_T / K)
  • ROI_case = R_T / C_a
